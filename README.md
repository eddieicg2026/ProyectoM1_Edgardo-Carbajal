# Generador de Paletas de Colores Aleatorio

Este proyecto es una aplicación web estática e interactiva que permite generar paletas de colores aleatorias con un solo botón. Ideal para diseñadores, desarrolladores o cualquier persona que quiera inspirarse con combinaciones de colores.

link a la propuesta:

https://eddieicg2026.github.io/ProyectoM1_Edgardo-Carbajal

---

## Funcionalidades

- Selección del tamaño de la paleta: 6, 8 o 9 colores.
- Selección de formatos: HSL o HEX.
- Visualización de cada color junto a su código.
- Bloqueo de colores para evitar repeticiones en la misma paleta.
- Guardado automático de la paleta generada en `localStorage`.
- Animaciones sutiles al pasar el mouse sobre los colores.
- Copia del código del color al portapapeles con un clic.
- Microfeedback mediante alertas para confirmar la copia.
- Diseño accesible y mejorado visualmente con bordes redondeados, sombras y efectos de foco.

---

## Tecnologías

- HTML5 semántico
- CSS3 con transiciones y efectos visuales
- JavaScript para la lógica interactiva y manejo del portapapeles

---

## Uso

1. Abrir el archivo `index.html` en un navegador moderno.
2. Seleccionar el tamaño deseado de la paleta y formato de colores en los menús desplegables.
3. Hacer clic en el botón "Generar paleta".
4. Hacer clic en cualquier color para copiar su código al portapapeles.
